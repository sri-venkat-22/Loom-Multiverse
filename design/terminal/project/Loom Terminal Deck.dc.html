§ 00

Where this starts

loom/tui/ does not exist yet. WP-1.1 through 1.5 have landed — contracts, the event log, config precedence, the ledger, init and status. Everything here sits in front of code still to be written.

So none of it is a recreation. It is the drawing that WP-8.1, 8.2 and 8.3 get built from.

Three things are treated as fixed: the banner block in SRS §3.2, the effort slider in §3.4, and the field order loom status already prints from cli.py.

The parity matrix in §3.1 is the brief. Behaviour parity, drawn in Loom's own hand — a warm charcoal ground, gold as stroke, and a weave for a mark.
